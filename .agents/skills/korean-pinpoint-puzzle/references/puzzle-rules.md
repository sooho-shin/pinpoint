# 한국어 Pinpoint 문제 규칙

## 좋은 문제의 형태

좋은 문제는 `모호함 -> 방향성 -> 확정성`의 흐름을 가진다. 플레이어는 단서 1~2에서 여러 후보를 떠올리고, 단서 3~4에서 후보를 줄이며, 단서 5에서 정답을 확신해야 한다.

기준 예시:

```text
단서 1: 경계
단서 2: 통과
단서 3: 도장
단서 4: 비자
단서 5: 여권
정답: 출입국
```

```text
단서 1: 암호
단서 2: 약속
단서 3: 열쇠
단서 4: 공개키
단서 5: 블록체인
정답: 암호화
```

## 단서별 역할

- 단서 1: 추상적이고 넓다. 정답의 분위기나 주변 개념을 건드린다.
- 단서 2: 첫 단서와 결합해도 아직 정답이 여러 개 가능해야 한다.
- 단서 3: 도메인을 좁힌다. 사회/기술/예술/과학 같은 영역이 보이기 시작한다.
- 단서 4: 강한 식별자를 준다.
- 단서 5: 정답을 확정하는 키워드를 준다. 단, 정답 문자열을 그대로 쓰지는 않는다.

## 금지 패턴

- 너무 쉬운 카테고리형: `김치`, `불고기`, `비빔밥` -> `한식`
- 단순 목록형: 같은 분류의 대표 예시만 나열하는 문제
- 정답 포함형: 정답이 `암호화`인데 단서에 `암호화폐`처럼 핵심 문자열이 직접 들어가는 문제
- 별칭 포함형: 정답이 `플라톤`이고 별칭이 `아카데메이아`라면, 단서에 `플라톤 정책`이나 `아카데메이아 학파`처럼 정답/별칭 문자열을 직접 넣지 않는다.
- 과도한 전문성: 5번째 단서까지 봐도 일반 사용자가 검색 없이 맞히기 어려운 문제
- 논란형 정답: 여러 정답이 동등하게 자연스러운데 대표 정답만 인정하는 문제

## 정답과 별칭

- 대표 정답은 가장 자연스러운 한국어 표현으로 둔다.
- `aliases`에는 띄어쓰기 차이, 영문/한글 병기, 흔한 약칭, 동의 표현을 넣는다.
- 인명은 한국어 표기와 원어 표기를 둘 다 고려한다.
- 작품명은 국내 통용 번역명과 원제를 둘 다 고려한다.

## 난이도

- 3: 대중 교양 수준. 5번째 단서에서 대부분 맞힐 수 있다.
- 4: 이 프로젝트의 기본값. 단서 3~4부터 사고가 필요하다.
- 5: 고난도. 문화/과학/역사 지식이 필요하지만 5번째 단서는 공정해야 한다.

기본 생성 난이도는 4 이상으로 둔다.

## 정책 config

자동 검증에서 사용하는 최소 품질 점수와 쉬운 정답 차단 목록은 `config/puzzle-policy.json`에 둔다. 금지/주의 정답을 늘릴 때는 문서만 고치지 말고 config도 함께 갱신한다.
