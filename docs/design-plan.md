# Figma 디자인 기획

## 방향

이 프로젝트는 디자인을 먼저 만든 뒤 코드를 작성한다. 따라서 초기 Figma 작업의 목적은 코드 생성이 아니라, 한국어 Pinpoint의 제품 경험과 디자인 시스템을 확정하는 것이다.

작업 순서:

```text
디자인 기획
→ Figma 디자인 시스템 생성
→ Figma 화면 생성
→ 디자인 검증 하네스
→ 앱 코드 구현
→ Code Connect 연결
```

Code Connect는 지금의 출발점이 아니다. Figma 컴포넌트와 코드 컴포넌트가 모두 생긴 뒤, 둘을 연결하는 후반 단계로 둔다.

## 벤치마킹 기준

LinkedIn Pinpoint는 여러 단서가 하나씩 공개되고, 이 단서들을 연결하는 공통 카테고리나 주제를 맞히는 daily word-association game이다. 벤치마킹할 핵심은 장식이 아니라 다음 구조다.

- 하루 한 문제
- 단서가 하나씩 공개됨
- 정답 입력이 중심 행동
- 적은 단서로 맞힐수록 성취감이 커짐
- 결과 공유가 쉬움

한국어 버전은 단순 초성퀴즈나 상식퀴즈가 아니라, 모호한 단서가 점점 하나의 답으로 수렴하는 지적 퍼즐 경험을 지향한다.

## 제품 톤

- 조용하고 집중도 높은 퍼즐
- 과하게 귀엽거나 캐주얼하지 않음
- 한국어 텍스트가 중심이므로 가독성과 행간을 우선
- 모바일 첫 화면에서 바로 게임을 시작할 수 있어야 함
- 카드 남용을 피하고, 핵심 퍼즐 보드를 화면 중심에 둠

## 핵심 화면

### Sign In

- Google 로그인 버튼
- 로그인하지 않아도 오늘 문제를 풀 수 있다는 보조 안내
- 랭킹 등록과 그룹 참여에는 로그인이 필요하다는 상태 안내
- 로그인 실패/취소 상태

### Nickname Setup

- Google 계정 이름 기반의 닉네임 초깃값
- 닉네임 입력
- 사용 가능/불가 상태
- 저장 버튼
- 랭킹과 공유 화면에 표시될 이름이라는 짧은 안내

### Today Puzzle

- 오늘 날짜 또는 회차
- 열린 단서와 잠긴 단서
- 정답 입력
- 제출 버튼
- 다음 단서 공개 버튼 또는 오답 후 자동 공개
- 진행 상태

### Result

- 성공/실패 상태
- 몇 번째 단서에서 맞혔는지
- 전체 단서
- 정답
- 공유 버튼
- 로그인 전이면 랭킹 등록을 위한 Google 로그인 진입
- 로그인 후 닉네임이 없으면 닉네임 설정 진입
- 오늘의 랭킹 진입 여부
- 다음 공개 안내

### Ranking

- 오늘의 랭킹
- 그룹 랭킹
- 단서 수, 풀이 시간, 제출 시각
- 내 기록 강조
- 비공개 상태에서는 Google 로그인/닉네임/그룹 참여 안내
- 비정상 기록은 운영자 검토 전까지 노출 제한

### Admin Review

- 후보 문제 목록
- 단서 5개
- 정답/별칭
- 품질 점수와 issue flags
- 승인/반려/수정 액션
- flagged ranking attempts 확인

## 디자인 원칙

- 첫 화면은 마케팅 랜딩이 아니라 실제 게임 화면이다.
- 텍스트가 UI를 지배하므로 타이포그래피와 spacing을 안정적으로 잡는다.
- 버튼/입력/상태표시는 반복 사용 가능한 컴포넌트로 만든다.
- 모바일 화면을 우선하고, 데스크톱은 폭이 넓어진 게임 패널 형태로 확장한다.
- 결과 공유 화면은 짧고 캡처하기 좋아야 한다.
- 랭킹은 압박감보다 가벼운 비교와 공유 동기를 주는 톤으로 설계한다.
