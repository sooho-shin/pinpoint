# AdSense 반복 반려 진단

확인일: 2026-07-24
대상: https://pinpoint-seven.vercel.app/

## 확인된 반려 상태

- AdSense 상태: 주의 필요
- 반려 사유: 가치가 별로 없는 콘텐츠
- ads.txt 표시: 찾을 수 없음
- AdSense 최종 업데이트: 2026-07-17 08:56 KST

## 실사이트 근거

- `/ads.txt`는 현재 HTTP 200과 `pub-4621241846705196` 선언을 반환한다. AdSense의 ads.txt 표시는 이전 크롤링 결과로 판단한다.
- 주요 소개·가이드·정책·아카이브 페이지는 비로그인 Googlebot 요청에 HTTP 200과 서버 렌더링 본문을 반환한다.
- 반면 sitemap에 포함된 지난 문제 상세 48개 중 고유 해설이 있는 페이지는 `블랙홀` 1개뿐이었다.
- 나머지 47개 상세 페이지는 정답·단서만 달라지고 소개, 단서별 설명, 배경 지식, 풀이 팁이 같은 기본 문구를 반복했다.
- `/ranking`은 Googlebot 기준 본문이 약 72자지만 색인과 sitemap 등록이 허용돼 있었다.

## 가장 유력한 근본 원인

사이트에 콘텐츠 페이지를 추가했어도 크롤러가 발견하는 URL 다수가 동일한 기본 해설을 반복하는 얇은 페이지였다. Google은 사이트 전체를 검토하며 자동 생성 페이지나 원본성이 낮은 페이지에 광고 코드를 두지 말라고 안내한다. 따라서 페이지 수 부족보다 색인 대상의 품질 비율이 반복 반려와 더 직접적으로 연결된다.

## 최소 수정

- 고유 해설 데이터가 있는 지난 문제 상세만 아카이브에서 링크한다.
- 고유 해설이 없는 상세 페이지는 직접 접근은 유지하되 `noindex,follow`로 처리한다.
- sitemap에는 고유 해설이 있는 지난 문제 상세만 포함한다.
- 상태형 화면인 `/ranking`은 `noindex,follow`로 바꾸고 sitemap에서 제외한다.
- 짧았던 FAQ·난이도·카테고리·한국어 연상 퍼즐·문의 문서와 색인 가능한 고유 해설에는 주제에 필요한 설명을 보강한다.
- 기존 게임, 아카이브 목록, 정책 페이지, ads.txt 동작은 유지한다.

## 재심사 전 검증

- 앱·DB·Figma 계약과 빌드가 통과해야 한다.
- 배포 후 sitemap에서 범용 해설 페이지와 `/ranking`이 빠졌는지 확인한다.
- 범용 해설 상세 URL이 `noindex,follow`를 반환하는지 확인한다.
- 고유 해설 상세 URL은 계속 색인 가능해야 한다.
- `/ads.txt`, `/robots.txt`, 주요 공개 페이지가 HTTP 200을 반환해야 한다.
